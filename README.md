# rdimitrov — Project Portfolio

This repository is an index of my software projects. It highlights work that is ready to share and will grow as more projects reach a presentable stage.

## Projects

### [Yugi — Deck Builder and Duel Prototype](https://github.com/rdimitrovv2922-lab/Yugi-app)

A browser-based Yu-Gi-Oh! project with account sign-in, a deck builder with server-side validation, two-player rooms, and an interactive duel board.

- **Built with:** HTML, CSS, JavaScript modules, Node.js, and SQLite
- **Status:** Active prototype. Card effects are currently managed by players, and there is no hosted demo.
- **Source code and setup:** [Yugi-app repository](https://github.com/rdimitrovv2922-lab/Yugi-app)

### [COOL Compiler Front End](https://github.com/rdimitrovv2922-lab/cool-compiler)

C++ and ANTLR4 lexer and parser for COOL. Semantic analysis and code generation are not implemented.
